# SnippetSphere

SnippetSphere is a full-stack MERN application that enables developers to securely store, organize, and share code snippets. It provides authentication, snippet management, search, tagging, and privacy controls to improve developer productivity.

## Features

- JWT Authentication & Authorization
- Secure Password Hashing with Bcrypt.js
- Create, Read, Update & Delete (CRUD) Snippets
- Public & Private Snippet Visibility
- Real-Time Search
- Tag-Based Organization
- Auto-Save Drafts
- One-Click Copy to Clipboard
- Download Snippets as .txt Files
- Responsive UI
- RESTful APIs

## Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JWT
- Bcrypt.js

## Installation

```bash
git clone https://github.com/rahul-nishad5708/SnippetSphere.git
cd SnippetSphere
npm install
```

## Run Backend

```bash
npm run server
```

## Run Frontend

```bash
npm start
```
